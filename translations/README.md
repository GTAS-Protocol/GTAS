# GTAS Specification Translations

This directory holds community-maintained translations of the Master Ground Truth Anchoring Standard (GTAS) specification.

## Authoritative Baseline
The English [`README.md`](../README.md) in the root directory remains the single authoritative, legally and mathematically binding Etalon specification.

## Translation Guidelines
- Maintain strict technical fidelity to the mathematical expressions and Bayesian formulas in the Master Specification.
- Avoid introducing regional or colloquial ideological framing.
- Submit new translations via Pull Request using the format `README.<language-code>.md` (e.g., `README.hu.md`, `README.zh-CN.md`).

## Available Languages
- **English (Master Specification)**: [`/README.md`](../README.md)
- *Community translations welcome via Pull Request.*
